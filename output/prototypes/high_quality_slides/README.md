# High-Quality Slides

A Claude Code skill that generates polished, self-contained HTML slide presentations using a research-first, narrative-driven 5-phase workflow. Say "create a presentation about X" and get a browser-ready deck with keyboard navigation, 16:9 layout, and smooth transitions -- no PowerPoint, no dependencies.

**Headline result:** One trigger phrase produces a complete `.html` slide deck that opens in any browser, navigates with arrow keys, goes fullscreen with F, and prints cleanly.

- [HOW_TO_USE.md](HOW_TO_USE.md) -- install the skill, trigger it, see output in 60 seconds
- [TECH_DETAILS.md](TECH_DETAILS.md) -- architecture, data flow, limitations, and why it matters
