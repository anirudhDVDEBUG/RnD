# AWS Well-Architected Review

**TL;DR:** A Claude Code skill that teaches Claude to review your Terraform, CloudFormation, IAM policies, and application code against all six AWS Well-Architected Framework pillars — producing prioritized findings with concrete fix recommendations. Includes a standalone Python analyzer for offline static analysis.

**Headline result:** Scans 4 sample files and surfaces 20+ findings across Security, Reliability, Cost Optimization, and Operational Excellence — from wildcard IAM policies to hard-coded secrets to single-AZ databases — in under 1 second with zero API keys.
