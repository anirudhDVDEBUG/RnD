# Tokenless Context Compression

One command to cut token usage by up to 50%+ through intelligent context compression for Claude Code agentic workflows.

## When to use

- "Reduce my token usage in this project"
- "Compress context to save tokens"
- "Optimize token consumption for this codebase"
- "Run tokenless to cut costs"
- "Help me use fewer tokens in my Claude sessions"

## How to use

### Installation

1. Install Tokenless globally via npm:
   ```bash
   npm install -g tokenless
   ```
   Or add it to your project:
   ```bash
   npm install tokenless
   ```

2. Alternatively, run directly with npx:
   ```bash
   npx tokenless
   ```

### Usage

1. **Run Tokenless in your project directory** to analyze and compress context:
   ```bash
   npx tokenless
   ```

2. **Review the optimization results** — Tokenless will scan your project files and generate compressed context representations that reduce token consumption while preserving semantic meaning.

3. **Apply the optimizations** — The tool configures your Claude Code environment to use compressed context, reducing token usage by up to 50% or more in agentic workflows.

### Key Features

- **Context Compression**: Intelligently compresses project context to minimize token consumption
- **Agentic Workflow Optimization**: Designed specifically for Claude Code agent-based workflows
- **Single Command**: Simple one-command setup — no complex configuration needed
- **Token Savings**: Achieves up to 50%+ reduction in token usage

### Tips

- Run Tokenless at the start of a new project or session for maximum savings
- Re-run after significant codebase changes to update compressed context
- Works best with large codebases where context windows fill up quickly
