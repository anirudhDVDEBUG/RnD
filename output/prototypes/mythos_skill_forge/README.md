# Mythos Skill Forge

**One command to scaffold, validate, and audit production-ready Claude Code skills.**

Mythos Skill Forge generates complete skill directories (SKILL.md, CLAUDE.md, hooks, templates) that follow Anthropic's conventions — so you can go from idea to installed skill in under 60 seconds.

**Headline result:** `python3 skill_forge.py forge --preset code_review` produces a 5/5 audit-passing skill directory, ready to drop into `~/.claude/skills/`.

- [HOW_TO_USE.md](HOW_TO_USE.md) — install steps, trigger phrases, first 60 seconds
- [TECH_DETAILS.md](TECH_DETAILS.md) — architecture, data flow, limitations
