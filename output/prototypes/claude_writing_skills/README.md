# Claude Writing Skills

**A 4-stage content pipeline (Research → Score → Rewrite → Publish) as Claude Code skills for long-form writers.**

Turn a YouTube URL or topic into a polished, publish-ready markdown article — scored and iteratively improved — without leaving your terminal.

## Headline Result

```
$ bash run.sh
Research: 5 key themes extracted from YouTube transcript (mock)
Score:    Draft scored 6.2/10 — weak intro, good structure
Rewrite:  Intro rewritten, score improved to 8.1/10
Publish:  output/published/article.md ready (frontmatter + TOC)
```
