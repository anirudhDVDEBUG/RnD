# Overkill -- Over-Engineer Everything

A Claude Code skill that takes any simple coding request and deliberately produces
the most absurdly over-engineered, enterprise-grade implementation possible --
complete with design patterns, custom exception hierarchies, circuit breakers,
and structured logging. Educational, hilarious, and fully functional.

**Headline result:** Adding two numbers now requires 400 lines of code, 3 pluggable
strategies, a circuit breaker, a Result monad, and a metrics dashboard.

```
bash run.sh
```
