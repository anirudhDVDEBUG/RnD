# Agent Design Patterns — 7x6 Framework

A queryable Python catalogue of **28 agent design patterns** organized in a 7-layer x 6-concern grid, based on the open-source companion to *Designing AI Agents* (Manning) by Jia Huang. Search patterns, get architecture recommendations, and explore composition chains — all offline, no API keys.

**Headline result:** Run `bash run.sh` and instantly see the full pattern grid, drill into any layer/concern, search by use case, and get a recommended architecture (e.g. "Autonomous Agent" = 6 composable patterns across 4 layers).

See [HOW_TO_USE.md](HOW_TO_USE.md) for setup and [TECH_DETAILS.md](TECH_DETAILS.md) for architecture.

**Source:** [huangjia2019/agent-design-patterns](https://github.com/huangjia2019/agent-design-patterns)
