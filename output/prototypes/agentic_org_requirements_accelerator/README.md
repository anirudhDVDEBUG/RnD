# Agentic Organization Requirements Accelerator

**Turn weeks of requirements analysis into hours using parallel agentic decomposition.**

Inspired by [how Endava builds an agentic organization with Codex](https://openai.com/index/endava), this tool runs four specialized analysis agents in parallel — Decomposition, Dependency Mapping, Technical Feasibility, and Spec Writing — to transform raw stakeholder requirements into a prioritized, cross-validated backlog with architecture implications and risk assessments.

**Headline result:** A 47-requirement enterprise project spec produced in ~2 seconds (mock demo) vs. the weeks-long manual process Endava reported before adopting agentic workflows.

## Quick start

```bash
bash run.sh
```
