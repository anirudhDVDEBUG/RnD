# Appshot Store Preview Generator

Generate App Store and Google Play preview screenshots and videos from a TypeScript config. Remotion + React + Tailwind under the hood, with Claude Code agent skills for AI-directed creative workflows.

**Headline result:** Define 5 scenes in a config file, run one command, get pixel-perfect 1290x2796 App Store screenshots and an MP4 preview video with transitions — no design tools needed.
