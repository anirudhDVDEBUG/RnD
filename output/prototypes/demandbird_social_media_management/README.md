# DemandBird Social Media Management — Evaluation Prototype

**DemandBird is an AI-native social media management tool for teams and agencies.** It provides multi-platform publishing (Twitter/X, LinkedIn, YouTube, Bluesky, Threads, Substack), content scheduling, analytics, and a content repurposing pipeline — all accessible via API and MCP server for Claude integration.

## Headline Result

Run `bash run.sh` to see a full content lifecycle in 10 seconds: create posts, schedule across 6 platforms, repurpose content into platform-specific variants, and view engagement analytics — all without API keys.
