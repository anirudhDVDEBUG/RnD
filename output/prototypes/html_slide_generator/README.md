# HTML Slide Generator (Claude Code Skill)

**One sentence:** Drop a SKILL.md file into your Claude Code skills folder and say "make me a presentation about X" — Claude generates a fully self-contained, navigable HTML slide deck in seconds.

## Headline Result

```
You: "Create a 10-slide pitch deck about our AI-powered recipe app"
Claude: writes recipe-app-pitch-slides.html (single file, 0 dependencies, keyboard/touch nav, works offline)
```
