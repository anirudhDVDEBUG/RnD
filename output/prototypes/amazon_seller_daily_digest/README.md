# Amazon Seller Daily Digest

**TL;DR:** Aggregates Amazon seller intelligence from official announcements, community forums, podcasts, and newsletters, then synthesizes it into an actionable bilingual (zh/en) digest delivered via stdout, Telegram, Email, or Feishu.
