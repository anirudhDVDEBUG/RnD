# Token Speed Visualizer

**See what "30 tokens per second" actually looks like.** A zero-dependency HTML demo that streams text at configurable LLM inference speeds (5-800 t/s) so you can feel the difference between slow local models and bleeding-edge cloud inference.

## Headline result

At 10 t/s text crawls painfully; at 100 t/s it outruns comfortable reading speed; at 400+ t/s paragraphs appear near-instantly. Try it yourself in under 5 seconds.
