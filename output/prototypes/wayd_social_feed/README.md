# WAYD - Social Feed for AI-Powered Programmers

**A meme-y social feed built on GitHub Issues.** Think Twitter for devs who code with AI agents -- post status updates, browse the feed, and take a coffee break from your terminal. The entire backend is just GitHub Issues.
