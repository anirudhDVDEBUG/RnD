# Agentic Organization Requirements Accelerator

Accelerate software delivery by applying agentic coding patterns to requirements analysis and organizational workflows. Inspired by how Endava builds an agentic organization, this skill helps reduce requirements analysis timelines from weeks to hours.

## When to use

- "Help me speed up requirements analysis for this project"
- "Set up an agentic workflow for software delivery"
- "Analyze these requirements documents and extract actionable specs"
- "Build an agentic coding pipeline for our organization"
- "Reduce our requirements gathering timeline"

## How to use

### Step 1: Gather and Structure Requirements

Collect all raw requirements sources (documents, tickets, stakeholder notes, existing specs). Organize them into a structured format:

```markdown
## Requirements Intake
- Source: [document/stakeholder/ticket]
- Raw requirement: [verbatim text]
- Domain: [functional/non-functional/technical]
- Priority: [critical/high/medium/low]
```

### Step 2: Agentic Analysis Pipeline

Break down the requirements analysis into parallel agentic tasks:

1. **Decomposition Agent**: Parse raw requirements into atomic user stories with acceptance criteria
2. **Dependency Mapping Agent**: Identify dependencies, conflicts, and gaps between requirements
3. **Technical Feasibility Agent**: Assess each requirement for technical complexity and effort
4. **Specification Writer Agent**: Generate detailed technical specifications from analyzed requirements

### Step 3: Cross-Validation and Consolidation

- Cross-reference outputs from all analysis agents
- Identify contradictions or ambiguities
- Produce a consolidated requirements document with:
  - Prioritized backlog of user stories
  - Technical architecture implications
  - Risk assessment and dependency graph
  - Estimated delivery phases

### Step 4: Iterative Refinement

- Present consolidated specs to stakeholders for feedback
- Use agentic coding to rapidly prototype ambiguous requirements
- Update specifications based on feedback loops
- Generate implementation-ready tickets with clear acceptance criteria

### Key Principles for Agentic Organization

- **Parallelize analysis**: Run multiple analysis tasks concurrently rather than sequentially
- **Structured outputs**: Every agent produces machine-readable, reviewable artifacts
- **Human-in-the-loop**: Stakeholders validate at key checkpoints, not at every step
- **Incremental delivery**: Ship analyzed requirements in batches rather than waiting for completeness
- **Traceability**: Maintain links from final specs back to original requirements sources
