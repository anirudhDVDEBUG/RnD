# datasette-agent Chat Demo

**datasette-agent** (0.1a4) adds an agentic, natural-language chat interface directly inside Datasette's Jump menu. Press `/`, type a question in plain English, and the agent translates it to SQL, executes it, and returns results -- no SQL knowledge required.

**Headline result:** Ask "Revenue by category" and get a formatted breakdown in seconds, right inside your Datasette browser tab.

## Quick start

```bash
bash run.sh          # offline demo, no API keys needed
```

See [HOW_TO_USE.md](HOW_TO_USE.md) for full install and live-browser instructions.
See [TECH_DETAILS.md](TECH_DETAILS.md) for architecture and limitations.
