# Director SKILL — AI Filmmaking

**Turn any scene description into professional shot lists, keyframe prompts, and AI video prompts — styled through 10 iconic director lenses (Spielberg, Kubrick, Wong Kar-wai, Nolan, Villeneuve, Wes Anderson, Tarkovsky, Lynch, Park Chan-wook, Ridley Scott).** A Claude Code skill designed for use with Runway, Kling, and Google Veo.

## Headline Result

```
Input:  "A lone astronaut discovers a garden inside an abandoned space station" + Tarkovsky style
Output: 5-shot breakdown with keyframe prompts + Runway/Kling/Veo video prompts
        — complete cinematic language (lens, lighting, color grade, movement) per shot
```

```
bash run.sh
```
