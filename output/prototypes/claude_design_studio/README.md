# Claude Design Studio

Generate professional HTML/CSS mockups — dashboards, landing pages, login forms, card grids — from a single command or natural-language prompt inside Claude Code. No API keys, no Figma, no dependencies beyond Python 3.10+.

**Headline result:** `bash run.sh` produces four production-quality HTML designs (dark dashboard, light landing page, login form, product grid) in under 2 seconds.
