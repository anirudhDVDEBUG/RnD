# Biodefense Threat Briefing Generator

A Claude Code skill that generates structured, actionable biodefense and pandemic preparedness threat briefings — covering natural pathogens, engineered threats, surveillance posture, and preparedness gaps in a single Markdown document.

**Headline result:** Run `bash run.sh` and get a full intelligence-style briefing with threat assessments, confidence levels, a preparedness scorecard, and prioritized action items — no API keys required.

- [HOW_TO_USE.md](HOW_TO_USE.md) — Install, activate, and run in 60 seconds
- [TECH_DETAILS.md](TECH_DETAILS.md) — Architecture, data flow, and limitations
