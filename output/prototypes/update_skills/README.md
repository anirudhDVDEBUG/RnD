# update-skills

**Keep all your Claude Code custom skills up-to-date with one command.** Scans `~/.claude/skills/`, detects which skills were installed from GitHub repos, and pulls the latest SKILL.md for each.

**Headline result:** Run `update skills` in Claude Code and every custom skill syncs to its latest upstream version — no manual `git pull` per skill directory.

- [HOW_TO_USE.md](HOW_TO_USE.md) — install steps, trigger phrases, first 60 seconds
- [TECH_DETAILS.md](TECH_DETAILS.md) — architecture, data flow, limitations
