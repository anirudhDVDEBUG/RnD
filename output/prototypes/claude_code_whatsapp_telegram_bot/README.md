# Claude Code WhatsApp & Telegram Bot

**TL;DR:** Turn WhatsApp and Telegram into Claude-powered AI assistants with voice transcription, image analysis, file processing, and RAG -- all runnable from an Android phone via Termux or any Node.js server.

**Headline result:** Send a voice note, photo, or PDF to your WhatsApp/Telegram bot and get intelligent Claude-powered analysis back in seconds, with multi-tool reasoning that chains web search, calculation, and document retrieval automatically.
