# Retro Book Game Converter

A Claude Code skill that converts classic 1980s BASIC game listings from vintage programming books (Usborne, etc.) into modern, playable browser games using vanilla JavaScript/HTML with a retro CRT aesthetic. Zero dependencies — just prompt Claude and get a working game.

## Demo: Mad House (Usborne Creepy Computer Games, 1983)

```
  ████████████████████
  █  $    ██   G    █
  █ ███      ████   █
  █      @       $  █
  █ ██████  ██████  █
  █ $       G       █
  █   ████████  ██  █
  █        $      E █
  ████████████████████
  @ = You  G = Ghost  $ = Treasure  E = Exit
```

Run `bash run.sh` to serve the game locally and play in your browser.
