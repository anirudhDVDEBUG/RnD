# Claude Mythos AI — App Setup Prototype

**An open-source frontend client for Claude that ships with prompt templates for creative writing, roleplay, worldbuilding, and custom system prompts — with SillyTavern-compatible formatting.**

Run `bash run.sh` to see all four prompt templates in action (mock mode, no API key needed).
