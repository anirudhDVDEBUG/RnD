# Data Craft - Themed Data Visualizations

Generate beautiful, self-contained HTML dashboards from any dataset using six visual idioms (Executive Dashboard, Infographic, Analytical Report, Comparison Matrix, Timeline/Flow, Scorecard) and six narrative voices (Analyst, Storyteller, Executive, Teacher, Journalist, Minimalist). Each output is a single HTML file powered by ECharts — no server, no build step, just open in a browser.

**Screenshot-worthy result:** A dark-themed Executive Dashboard with Journalist voice turns plain quarterly sales CSV into a polished KPI panel + interactive bar/line/pie charts in one command.
