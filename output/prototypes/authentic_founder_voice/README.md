# Authentic Founder Voice

**Strip the AI smell from founder emails.** This Claude Code skill detects and rewrites AI-polished founder communications (investor updates, pitch emails, YC applications) into direct, credible human voice — inspired by Paul Graham's warning that AI-written emails are immediately obvious and destroy credibility.

### Before / After

| AI-polished (detected as fake) | Authentic founder voice |
|---|---|
| "Dear Mr. Graham, I hope this finds you well. I'm the co-founder of DataSync, a revolutionary platform at the intersection of real-time analytics and enterprise collaboration..." | "Hi — I'm building DataSync. We pipe live database changes into team dashboards. 400 companies use it, mostly found us through word of mouth." |

**Result: 8 AI red flags caught, rewritten in 3 seconds, zero API keys needed for demo.**
