# Small Business Ops — Claude Code Skill

**TL;DR:** A Claude Code skill that gives small business owners 10 one-command operational workflows (Monday brief, invoice chase, month close, payroll, CRM maintenance, etc.) by connecting Claude to QuickBooks, Stripe, HubSpot, and Gmail via MCP connectors.

## Headline Result

```
  MONDAY BRIEF — Friday, May 22, 2026

  Last 7 days revenue:       $  5,980.00
  Outstanding (overdue):     $  8,900.00  (3 invoices)
  Top CRM opportunity:       Sarah Chen — $12,000 [negotiation]

  THIS WEEK'S PRIORITIES
  1. Chase 3 overdue invoices ($8,900 at risk)
  2. Follow up with Sarah Chen — negotiation stage
  3. Review contractor hours for payroll
```

## Quick Start

```bash
bash run.sh          # runs all 10 workflows with mock data
```
