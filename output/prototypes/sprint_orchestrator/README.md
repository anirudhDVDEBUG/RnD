# Sprint Orchestrator

**TL;DR:** A Claude Code skill that coordinates parallel development sprints across multiple chat sessions. You describe a project goal; it decomposes it into phased tasks, assigns agents, enforces dependency order, and tracks completion — validated in 17+ production sprints.

## Headline Result

```
Sprint: SaaS Landing Page — 3 phases, 7 tasks, 3 agents
All tasks completed in parallel phases with zero file conflicts
Acceptance criteria: 5/5 passed
```
