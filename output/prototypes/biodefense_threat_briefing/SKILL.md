# Biodefense Threat Briefing

Generate structured, actionable biodefense and pandemic preparedness threat briefings for public health stakeholders, biosecurity analysts, and government partners.

## When to use

- "Create a biodefense threat briefing"
- "Summarize pandemic preparedness posture for our region"
- "Generate a biosurveillance intelligence report"
- "Assess public health readiness for emerging biological threats"
- "Draft a biosecurity risk analysis document"

## How to use

1. **Gather context** — Ask the user for:
   - Geographic scope (national, regional, local)
   - Threat focus (emerging pathogens, engineered agents, natural outbreaks, dual-use research)
   - Audience (policy makers, lab directors, field responders, general public health staff)
   - Time horizon (immediate situational awareness vs. strategic long-range planning)

2. **Structure the briefing** using this template:

```markdown
# Biodefense Threat Briefing
**Date:** [YYYY-MM-DD]
**Classification:** UNCLASSIFIED (or as specified)
**Scope:** [Geographic / domain scope]
**Prepared for:** [Audience]

## Executive Summary
[2-3 sentence overview of current threat landscape and key takeaways]

## Current Threat Landscape
### Natural Biological Threats
- Emerging / re-emerging pathogens of concern
- Seasonal and endemic disease trends
- Zoonotic spillover risks

### Deliberate / Engineered Threats
- Dual-use research developments
- Biosecurity policy changes
- Known capability gaps

## Surveillance & Detection Posture
- Active surveillance systems and coverage
- Genomic sequencing and early-warning capabilities
- Gaps or blind spots

## Preparedness Assessment
| Domain | Status | Key Gaps | Priority |
|--------|--------|----------|----------|
| Medical countermeasures | | | |
| Laboratory capacity | | | |
| Supply chain resilience | | | |
| Workforce readiness | | | |
| Communications / public trust | | | |

## Recommended Actions
1. [Immediate action items]
2. [Short-term improvements (30-90 days)]
3. [Long-term strategic investments]

## Intelligence Sources & Confidence
- [Source types and confidence levels for each assessment]
```

3. **Apply these principles:**
   - Use plain, precise language; avoid jargon unless audience-appropriate
   - Clearly separate facts from assessments and recommendations
   - Flag confidence levels (high / moderate / low) for each threat assessment
   - Include actionable next steps, not just descriptions
   - Note information gaps honestly — do not speculate beyond available data
   - Respect dual-use sensitivity: never provide technical details that could enable misuse

4. **Output** the completed briefing as a Markdown document. Offer to export as PDF-ready format or slide deck outline if requested.
