# MemoryBridge — Cross-Tool AI Memory MCP Server

**One memory store, every AI tool.** MemoryBridge is an MCP server that gives Claude Code, Cursor, Windsurf, Gemini CLI, and any MCP-compatible AI persistent shared memory — using ~400 tokens instead of ~4,000.

**Headline result:** Store context in Claude Code, retrieve it instantly in Cursor or Windsurf — no re-explaining your project, no wasted tokens.
