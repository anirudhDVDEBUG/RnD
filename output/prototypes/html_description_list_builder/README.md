# HTML Description List Builder

A Claude Code skill that generates semantic, accessible HTML `<dl>` markup — with proper `<dt>`/`<dd>` structure, optional `<div>` grouping for CSS, and ARIA labeling. Based on [Ben Myers' "On the \<dl\>"](https://benmyers.dev/blog/on-the-dl/) (via [Simon Willison](https://simonwillison.net/2026/May/23/on-the-dl/#atom-everything)).

**Headline result:** Give it key-value data, get spec-correct description list HTML in one shot — no more guessing whether `<div>` wrappers are valid or how to handle multiple values per term.

See [HOW_TO_USE.md](HOW_TO_USE.md) for setup and [TECH_DETAILS.md](TECH_DETAILS.md) for architecture.
