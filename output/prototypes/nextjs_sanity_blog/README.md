# Next.js + Sanity Blog Builder (Claude Code Skill)

A Claude Code skill that scaffolds a complete, production-ready blog using Next.js 14 (App Router, TypeScript, Tailwind CSS) and Sanity CMS as the headless backend. Say "create a blog with Next.js and Sanity" and get a full project with schemas, GROQ queries, listing/detail pages, and an embedded Sanity Studio.

**Headline result:** One trigger phrase generates 15+ files -- post/author schemas, typed Sanity client, blog listing page, slug-based detail page with Portable Text rendering, embedded Studio at `/studio`, and Tailwind styling -- ready for `npm run dev`.
