# Datasette Agent Data Explorer

**Datasette Agent** is a conversational AI assistant that lets you ask questions of SQLite databases in plain English. It translates natural language into SQL, executes queries, and returns results — with optional chart generation via a plugin.

> **Headline result:** Ask "What percentage of global capacity is renewable?" and get back the SQL, a formatted table, and a summary — zero SQL knowledge required.
