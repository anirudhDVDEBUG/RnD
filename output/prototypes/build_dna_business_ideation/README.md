# Build DNA — Business Ideation from Your Unique Strengths

**TL;DR:** A Claude Code skill that interviews you about your skills, experience, and unfair advantages, then generates 3-5 personalized business ideas only you could build — each with market analysis, GTM plan, MVP roadmap, and a 72-hour action plan to your first dollar.

## Headline Result

```
Input:  "I'm a full-stack dev with a 10k dev newsletter and speak Spanish"
Output: 4 tailored business ideas with difficulty ratings, a week-by-week
        MVP build plan, and an hour-by-hour 72-hour launch playbook
```

## Quick Start

```bash
bash run.sh          # runs a full demo with mock founder profile
```

See **[HOW_TO_USE.md](HOW_TO_USE.md)** for installation as a Claude skill and trigger phrases.
See **[TECH_DETAILS.md](TECH_DETAILS.md)** for architecture, limitations, and why this matters.
