# Revenue Run-Rate Tracker

**Plot annualized run-rate revenue milestones as clean line charts from announcement data points.** Drop in dates and dollar figures from press releases or funding rounds, get a publication-ready matplotlib chart in seconds.

![Anthropic run-rate revenue chart](run_rate_revenue.png)

## Headline result

Anthropic's run-rate revenue trajectory: **$9B (Dec 2025) to $47B (May 2026)** — a 5x increase in five months, visualized in one script.
