# Research Proof

**Pressure-test any research claim in 60 seconds.** Generates falsifiable evidence plans, runs adversarial checks for bias and logical fallacies, locks verification criteria upfront (frozen verifiers), and outputs a structured proof ledger with per-claim verdicts.

## Headline Result

```
Claims tested: 4 | Supported: 1 | Refuted: 2 | Inconclusive: 1 | Overall confidence: LOW
```

The demo takes four common AI/LLM research claims and shows that only one survives the full adversarial pipeline — exactly the kind of signal you need before betting product decisions on a headline stat.

## Quick Start

```bash
bash run.sh
```

No API keys, no installs — pure Python 3.10+ stdlib.
