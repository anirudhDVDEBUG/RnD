# Loushang: Multi-Model Coding Orchestration

**TL;DR:** Loushang is an AI-native coding orchestration platform that lets you run multiple LLM agents (Claude, DeepSeek, Qwen, Kimi, Minimax) in a unified runtime with stateful sessions, tool governance, and full traceability. Think "multi-model CI for agentic coding."

## Headline Result

```
Session #a3f7: Plan(deepseek-r1) -> Implement(claude-opus) -> Review(qwen-max) -> DELIVERED
  3 files changed | 47 lines | 0 tool-policy violations | full trace saved
```
