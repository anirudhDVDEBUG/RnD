# Clean Bug Report

A Claude Code skill that writes human-first bug reports — no AI slop, no speculative root causes, no fake-minimal repros. Based on [Armin Ronacher's guidelines](https://lucumr.pocoo.org/2026/5/24/pi-oss/) for what maintainers actually want in issue reports.

**Headline result:** A side-by-side comparison showing a 29-line clean report vs. a 45+ line AI-slop report — with automatic detection of 10+ slop patterns stripped out.

See [HOW_TO_USE.md](HOW_TO_USE.md) for installation and [TECH_DETAILS.md](TECH_DETAILS.md) for how it works.
