# Datasette SQL Write & Stored Queries Demo

**TL;DR:** Datasette 1.0a31 adds first-class UI support for executing write SQL (INSERT/UPDATE/DELETE) and saving stored queries with parameterized forms — turning Datasette into a lightweight CRUD app builder without writing any application code.

**Headline result:** A single `bash run.sh` spins up a Datasette instance with a pre-populated database, executes write queries via the API, saves stored queries, and demonstrates parameterized form-based inserts — all in under 10 seconds.
