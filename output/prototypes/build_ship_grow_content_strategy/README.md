# Build Ship Grow Content Strategy

**TL;DR:** A Claude Code skill that generates complete content strategies, launch checklists, growth plans, and ready-to-post social copy for digital product launches -- all from a single product description. Drop the skill file into `~/.claude/skills/` and trigger it with "create a content strategy" or "build a growth plan."

## Headline Result

```
> "Help me create a content strategy for my product launch"

=> 5 content pillars, 4-week calendar, 11-step launch checklist,
   90-day growth plan with KPIs, Twitter thread, LinkedIn post,
   Product Hunt tagline, and an SEO blog outline -- in one shot.
```
