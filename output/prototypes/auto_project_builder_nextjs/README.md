# Auto Project Builder (Next.js + shadcn/ui + SQLite)

**One prompt, one complete web app.** This Claude Code skill autonomously generates a project idea, scaffolds a full Next.js + shadcn/ui + SQLite application, builds out pages/API routes/components, seeds sample data, and verifies everything compiles — all without human intervention.

**Headline result:** Run `bash run.sh` and watch a complete, runnable Next.js project materialize in `./generated_project/` — including TypeScript config, Tailwind CSS, shadcn/ui components (Button, Card, Input), SQLite schema with seed data, App Router pages, and REST API routes.
