# iNaturalist Wildlife Sighting Logger

A Claude Code skill that turns messy wildlife field notes into structured, upload-ready observation records for iNaturalist. Say "I saw some birds on my walk" and get a formatted Markdown report with species checklist, scientific names, quality-grade assessment, and upload reminders.

**Headline result:** 4 species from a single LA River walk -> a complete sighting report with seasonal flags, quality cues, and an iNaturalist upload checklist, generated in under a second.
