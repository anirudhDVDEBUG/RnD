# Coding with Beat — Terminal Music DJ for Claude Code

A retro pixel DJ that plays background music in your AI coding terminal with synced lyrics, smart playlists, and reactive audio that panics when your tests fail.

**Headline result:** Type `codebeat` and get a full TUI music player with Apple Music/QQ Music/local files — or add it as an MCP server so Claude Code can control your music hands-free.
